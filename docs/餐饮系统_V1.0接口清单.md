# 餐饮系统 V1.0 · 接口清单与 JSON 示例

> REST 风格，前缀 `/api/v1`。鉴权 JWT（Header `Authorization: Bearer <token>`，载荷含 tenant_id / employee_id / data_scope）。
> 配套《V1.0详细设计》《ER与时序图》。决策已落地：全国统一价、规格绝对价、出品部门按类型、品牌统一商户号、每店边缘网关、Go。

## 0. 通用约定

**统一响应包**
```json
{ "code": 0, "msg": "ok", "data": {} }
```
- `code=0` 成功；非 0 为业务错误码。

**分页**：`?page=1&size=20`，返回 `{ "list": [], "total": 0, "page": 1, "size": 20 }`。

**常用错误码**
| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 1001 | 未认证/Token失效 |
| 1003 | 无权限(数据范围或操作权限) |
| 2001 | 参数校验失败 |
| 3001 | 桌台状态不允许该操作 |
| 3002 | 商品在该门店不可售 |
| 4001 | 账单金额不一致 |
| 5001 | 打印任务下发失败 |

## 4. 商品中心

### 4.1 属性组 / 选项
```
POST /api/v1/catalog/modifier-groups
GET  /api/v1/catalog/modifier-groups
```
新建「规格」组（绝对价）
```json
{ "name": "杯型", "groupType": "SPEC", "selectType": "SINGLE", "required": true,
  "options": [
    { "name": "中杯", "price": 12.00, "isDefault": true },
    { "name": "大杯", "price": 15.00 }
  ]}
```
新建「做法」组（不加价）
```json
{ "name": "冰度", "groupType": "METHOD", "selectType": "SINGLE", "required": true,
  "options": [ {"name":"去冰","price":0,"isDefault":true}, {"name":"少冰","price":0}, {"name":"常温","price":0} ]}
```
新建「加料」组（加价）
```json
{ "name": "加料", "groupType": "ADDON", "selectType": "MULTI", "required": false,
  "options": [ {"name":"加珍珠","price":3.00}, {"name":"加椰果","price":3.00} ]}
```

### 4.2 商品 SPU
```
POST /api/v1/catalog/spus
GET  /api/v1/catalog/spus?storeId=1001          门店可售菜单(按 spu_store 过滤)
GET  /api/v1/catalog/spus/{id}
PUT  /api/v1/catalog/spus/{id}/price            调整全国统一价
POST /api/v1/catalog/spus/{id}/stores           设置适用门店
```
新建饮品（绑定规格/做法/加料组）
```json
{ "name": "珍珠奶茶", "categoryId": 60, "basePrice": 0,
  "productionDeptType": "BAR",
  "modifierGroupIds": [ 701, 702, 703 ],
  "applyAllStores": true }
```
新建炒菜（无规格，用 base_price）
```json
{ "name": "鱼香肉丝", "categoryId": 30, "basePrice": 28.00,
  "productionDeptType": "KITCHEN", "modifierGroupIds": [ 710 ] }
```
门店菜单响应（节选）

## 6. 点单（混合点单核心）

```
POST /api/v1/orders                            下单/加菜
GET  /api/v1/orders/{id}                        订单详情
POST /api/v1/orders/{id}/items/{itemId}/refund  退菜
```
下单请求（炒菜 + 饮品同单）
```json
{ "tableId": 2003,
  "items": [
    { "spuId": 4001, "qty": 1, "remark": "免葱",
      "methodOptionIds": [4101] },
    { "spuId": 5001, "qty": 2,
      "specOptionId": 7012,
      "methodOptionIds": [7021, 7025],
      "addonOptionIds": [7031] }
  ]}
```
下单响应（已计价 + 快照）
```json
{ "code":0, "data": {
  "orderId": 300001, "orderNo": "SH001-20260530-0007", "status": "ORDERED",
  "items": [
    { "itemId": 1, "spuName":"鱼香肉丝", "unitPrice":28.00, "qty":1, "amount":28.00,
      "productionDeptType":"KITCHEN", "modifiers":[{"groupType":"METHOD","name":"免葱","price":0}] },
    { "itemId": 2, "spuName":"珍珠奶茶", "specName":"大杯", "unitPrice":18.00, "qty":2, "amount":36.00,
      "productionDeptType":"BAR",
      "modifiers":[
        {"groupType":"SPEC","name":"大杯","price":15},
        {"groupType":"METHOD","name":"去冰","price":0},
        {"groupType":"METHOD","name":"半糖","price":0},
        {"groupType":"ADDON","name":"加珍珠","price":3}] }
  ],
  "totalAmount": 64.00 }}
```
> 大杯奶茶 unit_price = 规格绝对价15 + 加珍珠3 = 18，×2 = 36。

退菜
```json
// req (需 order:refund 权限)
{ "qty": 1, "reason": "客人不要了" }
// resp.data
{ "itemId": 2, "itemStatus": "REFUNDED", "orderTotalAmount": 46.00 }
```

## 8. 打印（内部 + 运维）

```
POST /api/v1/print-jobs/{id}/reprint           补打
GET  /api/v1/print-jobs?orderId=300001         打印任务状态
GET  /api/v1/printers?storeId=1001             打印机列表+状态
```

```json
{ "productionDeptTypes": ["KITCHEN"] }
```

## 9. 边缘网关 ↔ 云端（设备侧接口）

```
POST /api/v1/edge/register                     网关注册(store, sn)
GET  /api/v1/edge/print-jobs/pull              拉取待打印任务(在线长轮询/WS)
POST /api/v1/edge/print-jobs/{id}/ack          打印回执 {status:PRINTED|FAILED}
POST /api/v1/edge/sync/orders                  离线订单幂等上行(批量)
POST /api/v1/edge/sync/payments                离线收银流水上行(批量)
POST /api/v1/edge/heartbeat                    心跳+设备状态(打印机在线/缺纸)
```
离线订单上行（幂等）
```json
{ "orders": [
  { "orderNo":"SH001-20260530-OFF-0003", "opSeq": 5, "tableId":2003,
    "items":[ ... ], "payments":[ {"payMethod":"CASH","amount":64} ],
    "clientCreatedAt":"2026-05-30T12:30:00Z" }
]}
```
> 云端按 `orderNo + opSeq` 去重合并；现金账以门店为权威源补录。
